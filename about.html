关于我，以及这个小站

你好，我是

这里是我的个人博客，一名人工智能专业的学生，正在学习计算机视觉与深度学习，网络爬虫技术。这个博客是我给自己的思考整理器——把学到的东西写清楚，才算真的学会。

「教是最好的学。」——把每一次踩坑和每一次想通都记下来。

这里会写什么

  • 学习笔记：计算机视觉、深度学习、爬虫、工程部署的学习过程与踩坑记录；
  • 项目记录：做过的课程项目和练手小工具的复盘；
  • 随笔：生活里值得记下来的碎片。

这个小站是怎么搭的

  • 前端：手写 HTML / CSS / 原生 JavaScript，Markdown 由 marked.js 渲染，代码高亮用 highlight.js；
  • 后端：腾讯云 CloudBase 云数据库存文章，管理员在浏览器里用 Markdown 编辑并一键发布；
  • 托管：CloudBase 静态托管，免费额度，自带二级域名，无需备案。
