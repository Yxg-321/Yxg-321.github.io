如何发布文章

这个博客现在是纯静态的，文章存在仓库的 assets/data/posts.json 里。发文章的流程是：

  1. 在电脑上找到项目目录 E:\yxg\web\blog\；
  2. 编辑 assets/data/posts.json，按现有格式新增一篇文章（或用 Markdown 写好再粘贴进 markdown 字段）；
  3. 用 Git 提交并推送到 GitHub；
  4. 约 1-2 分钟后，网站自动更新。

文章格式示例

{
  "title": "文章标题",
  "category": "学习笔记",
  "tags": ["标签1", "标签2"],
  "date": "2026-09-17",
  "published": true,
  "summary": "一句话简介",
  "markdown": "## 正文标题\n\n正文内容，支持 Markdown 语法……"
}

提示：Markdown 支持 # 标题、**加粗**、- 列表、```代码块``` 等语法。

更简单的办法

如果你觉得手动改 JSON 麻烦，也可以：

  • 把想写的内容直接发给 AI 助手，帮你生成文章并部署上线；
  • 或者告诉 AI「想发一篇文章，内容是……」，让它来处理。
